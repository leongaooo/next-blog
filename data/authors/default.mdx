我是高立民（Leon Gao），写前端，也做 3D 和图形。习惯是先把东西在本地跑通，再把它做成一个别人能点开、能自己验证的页面。

## 在做的几个项目

**[ai-graph](/projects/ai-graph)** —— 把一段文案渲染成可复现的 SVG 场景插画：纸白、墨、青绿、琥珀，−30°/−15° 轴测，同一 seed 重跑逐字节一致。三张场景与门禁都写在[成果页](/projects/ai-graph)里。

**[obscura-ocr](/demo)** —— PaddleOCR 工作台，自托管部署、口令制访问。演示入口走[在线 Demo](/demo)，口令按日发放；把 OCR 做成可控、可交付的在线服务这件事，写在[交付门禁复盘](/blog/agent-delivered-gate-service)里。

**[LexiLoop（词回环）](https://github.com/leongaooo/LexiLoop)** —— 极简的文字轮播记忆工具，Electron + React + TypeScript + Vite。Lexis（词）+ Loop（循环）：用一个安静的循环界面背单词、句子或任何文本。

**[SVG to 2.5D Converter](https://github.com/leongaooo/SvgToThreeModel)** —— Vue 3 + Three.js，把平面 SVG 户型图转换成可旋转的 2.5D 墙体模型，同时保留图上的文字。给建筑可视化和 2D 蓝图用。

**[MindPilot](https://github.com/Amzing-Ai/mind-pilot)** —— AI 驱动的任务管理与个人成长系统，把每天要做的事和长期目标接起来。

**[Cesium-Kit](https://github.com/leongaooo/cesium-kit)** —— 开源的 Cesium.js TypeScript 工具库，给三维地理开发提供开箱即用的函数和工具。
